# Product refinement roadmap

The canonical [roadmap](../ROADMAP.md) distinguishes the published v2.0.0 baseline,
unreviewed baseline fixes, independent local review branches, active work,
isolated prototypes and research-only ideas. [Review branches](../REVIEW_BRANCHES.md)
is the entry point for the current checkouts and verification boundaries. Impact analysis, dry runs and Archify maps
are already part of that released baseline; their former “in progress” labels
were stale.

See the [README](../README.md#capabilities) for entry points, the
[research inventory](../RESEARCH.md) for verification and limitations, and
[release history](roadmap-history.md) for earlier milestones. This page is a
pointer, not a second independently maintained feature-status list.
